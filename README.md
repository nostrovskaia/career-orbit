# 🚀 Career Orbit — Бережный адвент-трекер поиска работы

Интерактивный 31-дневный маршрут по возвращению в профессиональную жизнь и системному поиску работы без выгорания.

Проект построен вокруг идеи **адаптивной нагрузки**: каждый день предлагает одно и то же карьерное направление в трёх вариантах сложности в зависимости от вашего текущего ресурса.

---

## 🧠 Продуктовая концепция: 3 уровня энергии

Поиск работы редко идёт по прямой линии. Чтобы не бросать процесс в дни усталости, в трекер встроены три режима, которые можно переключать в любой момент:

1. **🌧️ «Я сегодня просто человек» (`minimum` — 0 минут):** Открыть ячейку, прочитать поддерживающую мысль, выдохнуть и закрыть. День всё равно засчитан.
2. **🌱 «Я в строю» (`normal` — 15–30 минут):** Небольшой конкретный шаг (аудит блока резюме, сбор фактов для кейса), оставляющий осязаемый артефакт.
3. **🚀 «Я могу горы свернуть» (`maximum` — 45–90 минут):** Глубокая стратегическая работа, если сегодня есть силы и азарт.

### Основные правила системы
* Пропущенные дни не накапливаются и не вызывают чувства вины.
* Не нужно выполнять задания задним числом.
* Главная метрика — регулярное движение вперёд, а не идеальное прохождение.

---

## ✨ Технические особенности

* **Сборка единого панно:** Закрытые ячейки оформлены уникальными космическими иллюстрациями без текстовых спойлеров (видны только номер дня и тег). По мере открытия дней обложки исчезают, открывая фрагменты общей панорамы под сеткой.
* **Гибкий старт (`startDate`):** Календарь умеет отсчитывать 31 день подряд от любой указанной даты старта в `content.js`, включая переход через конец месяца и Новый год.
* **Контент-движок на `content.js`:** Вся программа из 31 дня, уровни энергии и правила описаны в декларативном JS-файле.
* **Автономность:** Написан на чистом HTML/CSS/JS без внешних библиотек, работает офлайн и через GitHub Pages.

## 🚀 Как использовать

1. Скачайте репозиторий и укажите желаемую дату старта в параметре `startDate` внутри `content.js` (формат `"ГГГГ-ММ-ДД"`).
2. Опубликуйте папку через **GitHub Pages**, чтобы открывать трекер с телефона или ноутбука каждый день.
3. Выбирайте уровень энергии в верхней панели, в подвале или прямо внутри карточки дня.
